# 苇舟江湖梦 · 报告设计语言规范（Design System）

> 统一管理 `产物/` 下全部 HTML 量化报告的视觉风格。单一权威样式表：`产物/theme.css`。
> 任何新报告只需 `<link rel="stylesheet" href="theme.css">`（位于子目录用 `../theme.css`），即可自动获得统一风格。

## 一、设计 DNA

| 维度 | 取值 | 说明 |
|---|---|---|
| 调性 | 宣纸 · 墨蓝 · 朱砂 | 文学数据报告：纸感底色 + 沉静主色 + 关键强调 |
| 标题字体 | `Noto Serif SC` / `Songti SC`（衬线） | 文学气质，仅用于 h1/h2/h3 |
| 正文字体 | `PingFang SC` / `Microsoft YaHei`（无衬线） | 数据可读性 |
| 圆角 | 12px（卡片）/ 10px（磁贴） | 统一 |
| 阴影 | 单层极淡 `0 1px 3px rgba(31,28,23,.05)` | 克制 |

## 二、Token 体系（改一处即可全局生效）

```
--bg:#f4f1ea   宣纸底      --surface:#fffdf8  卡片
--ink:#1f1c17  墨字        --muted:#6b6353    次要字
--line:#ddd6c8 描边        --primary:#2c5d8a  墨蓝(主色/数字)
--primary-d:#1f3a5f 深墨蓝(渐变深端/标题)
--accent:#8a3324 朱砂(关键标记/负向)   --gold:#b8860b 鎏金(次要/星级)
--band: linear-gradient(135deg,#1f3a5f,#2c5d8a)  标题渐变带
```

## 三、组件约定（class 语义）

- **标题**：`h1` 全局即"页面标题带"（墨蓝渐变 + 白字 + 衬线）；`<header>` 仅作语义包裹。副标题 `.sub`（居中次要字）；作者行 `.author`（朱砂居中）。
- **容器**：`.wrap` / `main` —— 最大宽 1180px 居中，左右留白。
- **卡片/区块**：`section` 与 `.card` 同一外观（纸白卡 + 细描边 + 淡阴影）。
- **统计磁贴**：多套历史写法统一为一种外观——`.cards>.card`（含 `.kpi-v`/`.kpi-l`）、`.kpis>.kpi`（含 `.kpi .v`/`.kpi .l`）、`.kv`/`.kl`、`.metric`、`.meta`、`.stat` 均呈现"大数字(墨蓝)+小标签(次要)"。
- **表格**：浅蓝表头 + 斑马纹 + hover 高亮；`td.nm`/`td.name` 加粗。
- **注释/提示**：`.note`（左侧墨蓝竖条）、`.warn`（朱砂浅底）、`.up`(绿)/`.down`(朱砂) 涨跌语义。
- **标签**：`.tag`（墨蓝）、`.tag.g`（金）、`.tag.r`（朱砂）。
- **页脚**：`.foot` / `.footer` 统一居中次要字。

## 四、复用的"生成提示"（Prompt）

> 生成《苇舟江湖梦》量化分析报告时，请遵循以下既定设计语言，不要另起炉灶：
> 1. 页面仅引入 `产物/theme.css`（子目录报告用 `../theme.css`），**不要内联 `<style>`**。
> 2. 页面标题用 `<h1>`（自动渲染为墨蓝渐变带），副标题用 `<div class="sub">`，作者用 `<div class="author">`；标题下方用 `<div class="wrap">` 包裹正文。
> 3. 区块一律用 `<section>` 或 `<div class="card">`；小标题用 `<h2>`（自动带墨蓝左边框）。
> 4. 统计数字用磁贴：`<div class="cards"><div class="card"><div class="kpi-v">数值</div><div class="kpi-l">标签</div></div>…</div>`，或 `<div class="kpis"><div class="kpi"><div class="v">..</div><div class="l">..</div></div></div>`。
> 5. 表格用 `<table><th>` 表头即可，样式由 theme.css 接管；图表(SVG)内联颜色保持数据语义，不受页面主题影响。
> 6. 配色只使用 Token：`--primary`(墨蓝) 作数据与主色、`--accent`(朱砂) 作关键/负向、`--gold`(金) 作次要强调，**禁止引入新的大面积色块**。
