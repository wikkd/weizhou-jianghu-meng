# WORKFLOW.md · 团队工作流总结

> 本文档从项目工作日志（`.workbuddy/memory/`）提炼，描述"作者（霜月）+ AI 助手 + 并行 subagent"三方的完整协作工作流。
> 按时间顺序：**文本获取 → 分章标注 → 量化分析 → 可视化 → 报告治理 → 迭代优化**。

## 0. 角色分工

| 角色 | 职责 |
|---|---|
| 作者（霜月） | 提供原稿、拍板方法学、确认破坏性动作、给出迭代反馈 |
| AI 助手（苇舟） | 执行流水线、写报告、派 subagent、维护记忆、报告安全等级 |
| 并行 subagent | 批量量化 / 报告归纳等重活，多 agent 并行，主上下文汇总 |

协作原则：**结论先行、结构清晰、有据可依**；所有产出可复现（脚本化），所有决策留痕（记忆日志）。

## 1. 文本获取与同步

1. **权威稿在金山文档**（kdocs 连接器，用户共享的"苇舟江湖梦.docx"，持续编辑中）。
2. 二进制 docx 无法通过 API 直拉（鉴权限制）→ 用 kdocs `read_file` 抽取正文（JSON 包裹 Markdown，图片为 base64）。
3. 本地重建：python-docx 重建 docx（踩坑：控制字符触发 XML 校验 → 加 clean() 移除 C0/C1；Pillow 重编码 JPEG 绕过 UnrecognizedImageError）。
4. 重建 docx 保留文字+图片，但 WPS 专有排版重置为默认；如需 100% 保真需手动导出。
5. 本地维护 `数据/full_text.txt`（纯文本，章标记行 = `Heading 1`）。

## 2. 分章与标注

- `01_split_chapters.py`：按章标记切分 → `数据/chapter_data/chap_*.txt` + `chapters_index.json`。
- **人工/subagent 标注**：按 `数据/chapter_data/tag_schema.md` 对每章打结构化标签（story_arc / narrative_pov / emotion_line / tags_free / 战斗 / 场景等），6 批产出 `tags_batch1..6.json`。
- `02_aggregate_tags.py`：聚合校验 → `all_tags.json`（**核心数据**，只聚合不重建）。
- ⚠️ 章节数变化时（59→60 章）标注层会滞后：新章无标注 = 派生产物缺该章（当前未决风险）。

## 7. 并行 subagent 模式（本团队特色）

- **批量量化**：5 个 general-purpose subagent 并行，各产 JSON + 自包含 HTML（人物网络/情感/词汇/推断/风格）。
- **报告归纳**：3 个并行 subagent 按「宏观文本 / 叙事情感 / 人物地理社会」三组读取 28 份 HTML 提取要点，主上下文汇总。
- **人物考究**：单 agent 全流程（Grep 定位 → 通读 → 交叉核对多数据源 → 产报告）。
- 使用前提：任务可切分为独立子任务；产物格式预先约定（JSON schema / HTML 自包含）；主上下文负责整合与一致性校验。

## 8. 可视化规范（HTML 报告铁律）

1. **内联 SVG 优先**：所有图表用内联 SVG，不依赖 ECharts/Plotly 等 CDN 或需动态加载的 JS 库（预览/沙箱环境 CDN 常不可达，本地回退不可靠，多次踩坑）。
2. 交互用 CSS `transition` + `:hover` 透明度变化 + 内嵌 `<title>` 原生悬停提示，零 JS 实现。
3. SVG 字体用具体栈：`font-family:'PingFang SC','Microsoft YaHei','Noto Sans SC',system-ui,sans-serif`。
4. SVG marker 固定色 `fill="#RRGGBB"`，避免 `context-stroke` 等 SVG2 特性。
5. 样式统一由 `产物/theme.css` 驱动（共享样式表，非内联）；新报告复用既有组件（q-card / meta / ev / badge.mut）。
6. **验证方式**：无头 Chrome（CDP）实拍截图确认渲染，再交付。

## 9. 迭代优化纪律（darwin 棘轮）

报告/功能迭代流程：**评估 → 改进 → 实测验证（截图对比）→ 保留或回滚**。

- 每次只改一个点，验证有效才保留，退步即回滚。
- 用户反馈驱动：如"风格与其他报告一致""时间线不渲染""用数据可视化再优化"等，逐条闭环。
- 对应 skill：`skills/01-darwin-skill`（自动评估 8 维度 + 棘轮机制）。

## 11. 踩坑经验库（高频复现）

| 坑 | 解法 |
|---|---|
| CDN 图表空白 | 全部改内联 SVG（见 §8） |
| 单字名子串污染 | 否定清单（影≠光影、空≠天空、福≠幸福） |
| 标注层与文本层章节数不一致 | 先补标注再重跑 02 聚合 |
| 写死章节数/字数 | 从 chapters_index.json 动态计算 |
| docx 控制字符/图片格式异常 | clean() 去控制字符 + Pillow 重编码 |
| 平均句长口径不一 | 统一分词口径或显式标注口径差异 |
| 沙箱内 trash 不可达桌面废纸篓 | 破坏性删除前告知用户此限制 |
