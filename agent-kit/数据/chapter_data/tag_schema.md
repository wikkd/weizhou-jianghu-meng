# 《苇舟江湖梦》章节标注 Schema（统一词表）

> 用途：为 59 个章节做结构化 tag 标注，作为后续量化处理（人物出场频次/共现、地点热度、情节类型分布、时间线、感情线走势）的统一输入。
> 原则：**词表受控**——所有分类字段必须从下方给定枚举中选取，严禁自造类别；人物/地点必须映射到下方规范名（含别名归一）。
> 来源约束：地点词表以来自正文的 19 个节点为权威基准（不依赖文档内嵌示意图）；人物词表以来自已有人物统计（49 个）。

---

## 一、输出格式（每个章节一个对象，批处理结果写成 JSON 数组）

```json
[
  {
    "chapter": 1,
    "file": "chap_01.txt",
    "word_count": 1683,
    "time_layer": "初入江湖",
    "main_locations": ["望岳镇"],
    "characters_present": ["任琅", "尚樱", "刘媛灵"],
    "chapter_type": ["日常/生活", "情感/感情"],
    "story_arc": "主线·任琅尚樱感情",
    "emotion_line": "分离/离别",
    "combat_intensity": 0,
    "narrative_pov": "第三人称全知",
    "key_events": "任琅月夜与尚樱比武落败，当夜离家远行；回忆半年前偷鸡杀狼往事，与刘媛灵等人结义。",
    "tags_free": ["少年", "离家", "比武", "麦田"]
  }
]
```

字段说明：
- `chapter` / `file`：章节号与文件名，从 `chapters_index.json` 对齐，**不得错号**。
- `word_count`：该章正文字符数（已给出，直接抄录即可）。
- 分类字段严格取下列枚举；多值字段（main_locations / characters_present / chapter_type / tags_free）用数组。
- `key_events`：中文简述（1–3 句），概括本章关键情节，供后续检索，不强制量化。

## 二、受控词表

### A. 时间层 `time_layer`（单选）
- `序章/前史`（童年、回忆、"半年前"等往事插叙）
- `初入江湖`（任琅离家初期游历）
- `江湖历练`（江湖闯荡、门派见闻）
- `庙堂初涉`（进入朝堂/官职/京城事务）
- `乱世将起`（局势紧张、叛乱酝酿）
- `战乱爆发`（川阴王起事、大规模交战开始）
- `大战/决战`（关键战役、正面决战）
- `战后格局`（大战结束、建都/善后）
- `未明/过渡`（难以归类的过渡章）

> 选取依据：正文中的时间提示词（"数年後""乱起""大战""战后"等）与情节显著转折。如本章含多个时段，取**主体**时段。

### B. 主地点 `main_locations`（数组，≤3，取主要发生地）
**规范名（权威基准，来自正文）：**
京城、卫京郡、南岭关、京墨渡口、川阴城、梨花川、梨阳、望岳镇、苏城、楚城、海郡、奉秋、石陵、夫文渡口、响城、海都、暮山城、浣冰郡、镜湖

**别名归一（文中出现下列写法时，映射到规范名）：**
- 京 / 卫京都 / 都城 → `京城`
- 宿冰都 → `浣冰郡`
- 川陵 → `川阴城`（仅在确指川阴地域时）
- 北梨岭 / 南梨岭 → 保留原词但标注为梨花川周边山岭；若仅泛指则归入 `梨花川`
- 大支渡口 → 类同渡口，确指则保留，否则并入最近渡口
- 其余未在列表中的真实地名（如 蒙城、坪州、子午郡、昌平、武都、方上、建武、清州、麓云山、角都、仙峰宫顶、南山主峰、奕剑峰）：**确指且重要则保留原词**写入数组；若为泛指山岭/小地点，归入最近规范地或省略。

> 凡写入 `main_locations` 的名称，若不在上方规范名内，视为"扩展地名"，下游聚合时会单独归类，不影响主量化。

### C. 出场人物 `characters_present`（数组）
**规范名（49，含别名归一）：**
任琅、尚樱、陈奉天（别名：川阴王）、夏叶、刘笑岩、影、许达、刑布、苏雨、赵骁、马远、王慕、李博、张潇璃、聂林、苏沐文、赵翔、陆仲、尚衫虎、黄亚钊、虞环、程廖、纪田、武蒯、范豪、叶云、秦阳、夏穗良、法慧、韩德、谢仁玄、张百慧、王监军、安弈霖、安明、刘媛灵、张洵、张览、王奔、赵思俪、李叔、刑泰、金雷、雷光、陈王、阮盛、楚笙、刘安

**归一规则：**
- 文中"川阴王""王爷""反王"等指陈奉天时 → 写 `陈奉天`。
- 仅被**提及/回忆**而未实际出场者，不计入（除非该章核心就是回忆其事迹，则可计入并备注）。
- 路人/无名群体（"几个村民""士兵"）不计入；确有姓名但未在列表者，保留原词写入（扩展人物）。

- `战斗/武斗`

- `谋略/权谋`
- `情感/感情`

### F. 感情线 `emotion_line`（单选）

### G. 战斗强度 `combat_intensity`（序数 0–3）
- `0` 无战斗
- `1` 低（小规模冲突/切磋）
- `2` 中（局部战斗/小规模交战）

### H. 叙事视角 `narrative_pov`（单选）
- `任琅限知`（主要随任琅视角）
- `尚樱限知`
- `第三人称全知`
- `多视角切换`

### I. 自由标签 `tags_free`（数组，可选）
面向后续主题建模的关键词（如"比武""潜入""中毒""身世""盟约""背叛"等），每章 0–6 个，用正文原词。

## 三、标注注意事项
1. **先读后标**：务必打开对应 `chap_XX.txt` 通读再标注，不得凭空推断。
2. **对齐编号**：输出对象的 `chapter` 必须与文件名号一致。
3. **词表纪律**：分类字段只能取枚举值；人物/地点必须归一。
4. **多值不滥**：main_locations ≤3、characters_present 只列真正出场者、chapter_type 只列显著类型。
5. **不确定就保守**：无法判断的时段/故事线用 `未明/过渡`、`未明`；不要硬凑。
6. 输出为合法 JSON（数组），写至指定 `tags_batchN.json`，并打印 "BATCH N DONE: k chapters"。
