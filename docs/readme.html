部署模型

  • master = 网站工程（根）+ 文学/ 工程资产（.gitignore 屏蔽 文学/产物/）
  • gh-pages = master 原样 + 1 个「量化报告产物」commit（每次部署确定性重建，force-with-lease 推送）
  • 日常更新：提交 master → bash deploy.sh（产物来源 Desktop/image/_agentkit_stage/产物/，该目录不可删）
