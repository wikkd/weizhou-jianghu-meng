# content/ —— Wiki 词条源

- 每个词条一个 `.md`，放在对应命名空间目录（人物/章节/地点/组织/术语/诗词）。
- frontmatter 字段：`title`（必填）、`ns`（必填）、`aliases`（列表，自动生成重定向页）、`summary`、`tags`、`infobox`（键值对；人物/章节的统计键缺省时自动从 knowledge_base.json 回填）。
- 正文支持：段落、`## 小标题`、`- 列表`、`**加粗**`、`[[词条链]]`（三种写法：`[[任琅]]`、`[[章节/十一]]`、`[[章节/十一|显示名]]`；未创建词条显示为红链）。
- 信息框统计数字**不要手写**（除身份等描述性字段外），构建时自动回填，保证与 kb.html 同源。
- 改完跑 `python build_wiki.py` 重新生成 `wiki/`，再 `bash deploy.sh` 上线。
